# Vijay Supermarket 🛒

A modern, premium, mobile-first web frontend for **Vijay Supermarket** (located in Mogappair East, Chennai). Designed with Expressive Material 3 principles to showcase physical store offerings, everyday essentials, festival promotions, family savings cards, and apartment delivery services.

---

## 🌟 Key Features

- **Expressive Material 3 Design**: Built using vibrant color tokens (Deep Emerald, Harvest Gold, Warm Cream), smooth micro-interactions, floating CTAs, and responsive glassmorphism modals.
- **12 Interactive Product Categories**: Includes Fruits & Vegetables, Groceries & Staples, Dairy & Bakery, Snacks & Namkeen, Beverages, Personal Care, Household & Cleaning, Baby Care, Frozen & Packaged Foods, Spices & Masalas, Organic Products, and Festival Items with in-store shelf/aisle location maps.
- **Everyday Essentials Showcase**: Product filtering by category, search bar with real-time matching, MRP savings indicators, and detailed stock & shelf location modals.
- **Apartment & Bulk Order Inquiry**: Interactive lead-generation modal and contact form tailored for residential gated communities in Mogappair.
- **Family Savings Loyalty Program**: Loyalty membership inquiry modal (Silver, Gold, Platinum tiers) with instant confirmation toasts.
- **Store Info & Directions**: Live operating hours display, Google Maps location integration, direct phone call, and WhatsApp quick connect.

---

## 🚀 Tech Stack

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + Lucide Icons
- **Design Principles**: Google Material 3 Expressive System

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SreeAdithya123/vijay-supermarket.git
   cd vijay-supermarket
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
